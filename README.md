<h1>Desmosify</h1>
Desmosify is a project made on a whim to convert videos directly into the Desmos calculator. It also includes a way to render them into videos, so you can share them with your friends and preview without lags.
<h2>Why?</h2>
I saw a new trend on Instagram with people recreating different Anime Openings in Desmos. They were generated by their own software like this, so I decided to make my own, to learn more about Bezier curves, vector graphic, and Desmos in general.
<h2>Usage</h2>
Visit https://desmosify.heyn.live to use the website.

This website is static, which means that it does NOT need a server to run, only serving files is enough.
